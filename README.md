## Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- A text editor or IDE (VS Code, IntelliJ, Eclipse)

### Compilation & Execution

To compile a Java file:
```bash
javac ProgramName.java
```

To run the compiled program:
```bash
java ProgramName
```

**Example:**
```bash
javac Quiz3.java
java Quiz3
```
